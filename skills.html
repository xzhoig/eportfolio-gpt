My process

Understand the task.
Make the next step clear.

01 / PLAN

Start with the purpose.

Identify the audience, the content, and the main action. Sketch a layout before adding detail.

02 / BUILD

Keep the structure clean.

Use clear HTML, reusable CSS, and JavaScript functions with one understandable responsibility.

03 / REFINE

Test the experience.

Check links, small screens, keyboard access, and feedback states. Improve what feels unclear.

Built for CIS222

The personal portfolio

The problem

Present a student’s background clearly while demonstrating the core web design techniques required by CIS222.

The approach

Build seven separate HTML pages around a consistent layout system. Give visitors a direct route to experience, education, skills, projects, and contact information.

Implemented features

  • Shared external CSS and JavaScript across every page.
  • Responsive layouts, a mobile menu, and accessible focus states.
  • Theme switching, project filtering, native dialogs, and scroll animation.

What I’m learning

Consistent spacing and clear navigation do more for usability than adding decoration to every element.

Project status. Implemented in this submission. All pages and interactions are available locally.
Sample interface concept

Focus, a student task board

The problem

Students can feel overwhelmed when coursework and personal tasks compete for attention.

The approach

Use a simple three-column structure and concise task cards. Keep the most important next action easy to find.

Planned features

  • A proposed add-task button with input validation.
  • A planned status control for moving tasks between columns.
  • A planned local-storage option for keeping tasks between visits.

What I’m learning

Start with a clear information structure before writing interaction code. Each state should be understandable on a small screen.

Project status. Illustrative concept. The task application is not implemented; the inline SVG shows the proposed interface.
Sample design study

Reading Room, a tech hub

The problem

Useful tutorials are easy to lose among browser tabs and long, unstructured bookmark lists.

The approach

Create a readable card layout, meaningful topic categories, and a welcoming visual hierarchy with generous whitespace.

Planned features

  • A proposed topic filter for quickly narrowing articles.
  • A planned reading-status indicator for each tutorial.
  • A responsive article layout with consistent typography.

What I’m learning

Design around the reading task. Clear titles, useful categories, and comfortable spacing make content easier to scan.

Project status. Illustrative design study. The article hub is not implemented; its image is an original SVG interface mockup.

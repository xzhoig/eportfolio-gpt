CIS222 Web Design and Development | Individual Assignment (30%)

QUICK START
1. Extract the whole ZIP. Keep the nelson-portfolio folder intact.
2. Add your portrait as images/profile.jpg (see images/README.txt).
3. Open index.html in a current version of Chrome, Edge, Firefox, or Safari.
   No installation, build command, internet connection, or web server is needed.
4. Follow the navigation links to explore every page.

HOW TO DEMONSTRATE THE INTERACTIONS
- Resize the browser to less than 900 px wide and open the mobile menu.
- Press Escape to close it; use Tab and Enter to navigate with the keyboard.
- Use the moon/sun button to change theme. Your preference persists where
  the browser permits local storage (file:// rules vary by browser).
- On Skills, filter by Technical, Design, or People & process.
- On Projects, filter the gallery and open a case study. Escape closes it.
- Expand the details on Experience, Education, and Project briefs.
- Use Copy email in the contact section. If clipboard access is blocked,
  an on-screen message displays the address for manual copying.
- Use Print profile on Personal information to open a clean print layout.
- Scroll down to reveal the back-to-top button and reading progress line.

CONTENT AND CUSTOMISATION
The supplied name, email, institution, program, start year, career direction,
and hobbies are used throughout. Working roles and additional skill examples
are illustrative. Two projects are SVG interface concepts, not working apps.
The portfolio itself is the implemented project. Sample content is labeled on
the pages; replace it with your real experience before applying for jobs.

No third-party scripts, remote images, remote fonts, tracking, or dependencies.
The contact links open the user's email application using mailto; there is no
server-side contact form. Dark mode uses localStorage when available.

To change the visual theme, edit the colour tokens at the top of style.css.
To change copy, edit the appropriate HTML file directly. Every page has real
static content, so its structure and links remain available without JavaScript.
JavaScript progressively adds optional features rather than rendering pages.

Before submitting, add your photo, review the sample content, and make sure
you can explain the HTML, CSS, and JavaScript to your lecturer.
